# 通用 Agent 开发版本同步

公开 main 停留在 2026 年 7 月的长篇写作版。本分支先以独立源码快照同步当前通用工作台，再单独提交文件工作流修复，供逐提交审阅。没有将开发机的原始 Git 历史复制到公开仓库。

同步内容是 React 工作台、FastAPI/SQLite 运行时、Electron 浏览器宿主、接口合同、内置适配器、启动与打包代码及仓库测试。开发机的数据库、凭据、会话、书库、私人交接、研究笔记、临时验收目录和共享 Skills 不随此快照发布。

这是 Windows 源码开发版。文件工具的修改记录与撤回、命令指定观察范围的恢复、Office 文字提取、持久命令会话、普通聊天和共享浏览器都有实现；完整子 Agent、独立旁问和干净机器安装发行仍待建设。旧版 evaluation/evidence 目录是历史资料，不代表当前验收。

最终修复及验证结果见相邻的 agent-file-workflows.md。整份同步较大，建议先看修复提交，然后按需查看公开基线与当前运行架构的差异。
