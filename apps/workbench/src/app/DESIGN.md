# 工作台当前设计约定

2026-09-16：以作者最新要求为准，先把通用 Agent 做顺，小说专业方法交给 Skills。
现有工作区、正文编辑和修改记录继续保留，不因名称或摆法调整丢掉能力。

## 布局

- 左栏两段：「对话」（没打开文件夹的对话）和「项目」（打开过的文件夹，书也是文件夹），支持新建、改名、置顶、删除、折叠和调宽。
  「项目」标题右边「添加」：新建空白文件夹 / 打开已有文件夹。选文件夹是中间一页（文件夹由后端列，浏览器自带的选框拿不到完整路径），
  作者亲手选的文件夹就算信任。
- 左栏搜索同时提供标题与历史正文。默认全部对话，可选择当前项目或自由对话；正文按消息当时所属项目过滤，标题按会话当前项目过滤。正文显示真实说话人、时间、出处与摘录，点击在原文阅读窗查看相邻消息和长原文，不切当前对话或改输入草稿。
  搜索有等待、空结果、失败重试、分页和刷新状态，失败不能伪装为空。输入/范围变更作废旧请求和原文窗口，Escape 清搜索回导航。复用后端原消息与脱敏，不复制到长期记忆，也不为搜索创建模型任务；只检索消息正文，不包含工具日志或附件全文。
- 中间默认显示当前选中的 Agent 对话，顶栏工作区菜单显示当前文件夹或「自由对话」，可切换关联、打开或新建文件夹，旁边显示开着的文件。设置从左下角打开。
  多条对话可以同时运行；正在生成或等待发送确认时仍能切换、新建对话。切换只更换观察范围，后台任务继续，返回时恢复历史和事件流。
  左栏根据后台会话状态显示进行中标记，定期刷新并在窗口重新获得焦点时核对；悬停操作不遮住运行标记。侧栏收起后的新对话入口同样可用。
  健康检查异常只暂停观察，不清空当前会话、已读消息、流式尾段或侧栏列表；离线仍可编辑原会话草稿，发送与引导等待服务恢复。恢复时保留已读历史，从上次完整读取位置补齐缺页，并核对原任务和发送回执，不自动重发任务。读取失败保留原文，提供「重新读取对话」；明确换项目或服务确认原会话已不存在时才清理原观察状态。
- 右侧是文件、修改与当前对话的命令，文件按路径打开、编辑和查看差异。可调宽、放大和收起。
  未打开项目的对话也能从顶栏「修改」查看文件工具的记录、差异和撤回；打开项目时，项目文件与当前对话中的其他文件合并按时间显示，每条标明来源。
- 左右分隔线可拖动或用方向键调宽，双击恢复默认；Escape 或取消拖动恢复原宽度。宽度在本机记住，窗口变窄时临时约束两侧占用，不覆盖保存的偏好。
  常规右栏最多 900px，放大模式按可用空间展开；窄桌面优先保留对话阅读空间。输入框随分栏和窗口变化重新换行、调整高度，设置往返后恢复。
- 窄屏只显示当前选择的一栏，底部切换；隐藏栏不能留下可见子元素叠印。
- 作者 2026-10-11 明确以电脑为使用场景。设计与体验验收优先桌面；已有窄屏兼容保留，不将其作为这轮优化重点。
- 打开的文件路径提供给当前对话，作者也可以用 @ 引用文件，点击消息里的文件名打开。
  设置或选文件夹页面覆盖工作台时，界面与请求共同清除当前文件；返回文件面板后共同恢复。
- 设置和选文件夹页面首次打开时加载，加载中保留明确状态；对话组件继续保留草稿与会话状态。

## 主界面整理（2026-10-18）

- 三栏标题共用 `--zm-head-h`；消息与输入区共用阅读宽度和 `--zm-thread-inset`，避免同一列里出现两套左右边界。
- 左栏当前对话用中性底色、字重和细强调边辨识，项目中的对话保留明确缩进；侧栏样式由 `sidebar.css` 管理。
- 输入正文与附件、权限、发送放在输入区上半部；模型服务、模型、思考强度和容量放在同一容器的底栏，直接可见、可操作。模型下拉仍在发送 form 外，选择模型不触发发送。用量和缓存保留在回答下，详情支持键盘展开。
- 右栏由 `WorkspacePanel` 负责导航与展示，顶部合并来源、返回、放大与页签；方向键、Home/End 切换页签。文件名与操作放在同一行，状态与预览模式放在下一行。
- 项目保存与会话文件撤回仍由原有数据层及 Root 持有，面板展示拆分不改变正在进行的操作归属。
- `useConversationScroll` 统一更早消息的加载、重试和位置恢复，顶部与历史刻度共用同一请求状态。切换会话或项目使旧请求及延迟滚动失效，返回原会话也不接受上一次访问的回调。
  向前加载以正在阅读的消息和它在窗口中的位置为锚点，同时到来的新回复不计入头部位移；等待时继续滚动或回到最新，按用户后来的操作恢复。
  消息同步从上次完整读到的位置补齐分页，发送回执不代表中间历史已读。阶段回复、任务收尾与后台接续共用补页逻辑，更新请求取消被替代的旧读取。
  补页失败保留已读历史及流式文字，独立显示「重试同步记录」，不重发任务、不清草稿；任务本身失败时仍可重试读取记录。
- 长历史虚拟化、消息渲染职责拆分仍需后续处理；两套修改记录的导航已合并，底层版本与撤回各自保留。

## 修改记录阅读（2026-10-29）

- 对话卡、项目修改与对话文件修改共用差异视图。长行由界面换行，原始缩进、空白与行边界保留；大片相同行默认保留前后各三行，按钮展开后可读全部原文。
- 历史“已保存”描述当时的操作。详情重新读取磁盘确认当前差异与撤回条件；重新核对期间保留记录标题，暂停旧差异和撤回，失败允许重试。
- 文件被外部改动时就地显示当前原因，保留现有内容。记录标题使用文件名，完整路径放在详情和列表次行，避免同一长路径重复撑满标题。
- 样式由共享 diffView.css 管理，平台提交由运行时 file_commit 管理；展示不接管 journal/ChangeSet 的保存和撤回事实。

## 文件到对话（2026-10-18）

- 文件工具栏可将当前文件加入对话；选择原文、排版预览或编辑草稿中的文字后，显示选段来源、字符数和“加入对话”。选择后可用键盘进入操作栏，引用追加到当前对话草稿，焦点回到输入框。
- 原文和编辑选段带行列范围；排版预览只标“预览选段”，不生成源文件行号。代码显示工具栏不进入引用正文。
- 未保存的编辑内容标为“未保存草稿”；无选区时引用完整草稿，有选区时只引用选段。引用不保存文件、不自动发送，保留已有对话输入和文件草稿。
- 选段完整传递，保留缩进、换行及内嵌围栏。用户消息与 Agent 回答共用 Markdown 解析；附件只从普通文本节点中的文件引用识别，代码和已有链接不另行附加文件。
- `FilesPanel` 管文件树与持久草稿所有权，`FileView` 管读取、编辑、选择与工具栏；保存和撤回继续走原有版本及修改记录机制。当前引用是可编辑的消息正文，还没有独立批注条目管理。
  文件保存响应和恢复查询都失败时显示「保存待确认」，草稿同时保留原修改编号、提交内容和服务端文件哈希；重试或刷新后先读原记录，已落盘的保存不重复创建或写入。哈希使用服务端保留编码与换行后的值，不用编辑框的 UTF-8/LF 重算。期间继续编辑的新稿保留，确认旧保存并核对当前文件仍是该版本后才更新草稿基准；外部又有改动则保留原稿并提示核对。
- 右栏修改记录的编号、审核版本或状态变化时，对话结果卡重新核对服务端；对话里放弃修改也通知右栏刷新。读取序号和会话令牌继续阻止旧响应覆盖新状态。

## 视觉基础（2026-10-07）

- 当前采用连续分栏、细分隔线与中性底色；青绿色区分主要操作和选中状态，成功、提示和失败各用自己的语义色。
- 字号、间距、圆角、前景和背景共用 `zm.css` 的 `--zm-*` 变量；暗色强调色配专用前景色，按钮图标保持清晰。
- 设置使用独立整页目录与内容区，打开时隐藏会话侧栏，但不卸载对话组件；关闭回到原对话并保留输入草稿。
  模型设置在宽桌面采用左侧服务目录、右侧连接与模型表单；窄桌面将服务目录移到上方横向滚动。模型清单使用紧凑行，详情按需展开。
- 弹出菜单和确认框挂在 `.zm` 主题根节点内，固定定位绕开滚动区；继承背景、前景和字号，长菜单内部滚动，窄屏保持在视口内。
- 视觉调整保留数据与操作入口。更深入的功能吸收继续按 `docs/research/吸收台账.md` 推进，布局和数值可随真实使用反馈改进。

## 聊天与模型设置整理（2026-11-05）

- 默认侧栏 280px，长标题最多显示两行；尊重已保存的拖动宽度。对话与输入区共用最大 1040px 阅读宽度，窄桌面仍为对话保留原有最小空间。
- 原模型服务失效时单独显示原因；有可用模型时按钮打开原生选择器，缺少候选时进入设置。只有作者实际选中模型才更新当前会话，不自动替换绑定。
- 模型设置采用服务目录与编辑区，地址、密钥、模型与保存放在同一页；目录可选，模型可直接输入。更多模型、诊断、高级参数按需展开，普通文字测试结果原位显示。切服务和跨设置页分别保留资源草稿；关闭设置列出未保存资源。刷新浏览器仍会丢失设置内存草稿，离开提醒不能代替持久恢复。
- 停止时如果后台已暂停队列，前端暂停请求遇到版本冲突后只读回确认；确实已暂停才消除冲突。未暂停或读回失败保留原错误，不重放队列修改，也不丢弃待发消息。

## 设置与记忆（2026-11-06 重建）

- 设置包含通用、模型服务、MCP 工具、技能库、记忆、项目说明、关于七页；通用合并外观和聊天偏好，由 `settings/registry.ts` 统一登记。
  搜索先展开目标区域或打开记忆分页，再定位到具体选项；记住上次分类；返回和关闭共用未保存检查。作用范围在相关操作旁解释。
  已访问分类和分页在设置内部保留草稿；模型、MCP、记忆和技能编辑关闭设置时统一检查，切换分类不直接丢稿。外观和聊天偏好写入当前浏览器成功后才生效并显示已保存；写失败保持原选择、原位提示并可重试，可恢复默认。
  `SettingsDisclosure` 保留折叠区域草稿及 aria-expanded；记忆的 `SettingsTabs` / `SettingsPane` 统一 tab/tabpanel 语义，左右、Home/End 键可切换；隐藏内容不进入焦点顺序。搜索依照可见目标定位，不能落在隐藏分页。
  模型表单状态、异步请求和保存集中在 `useModelServices`；基础转换在 `modelForm`，页面只组合服务目录、基础表单与可展开的功能区。外观、偏好、项目说明和关于独立于设置外壳。
- 「聊天偏好」放思考展开、连续工具分组和本页新建议卡片的自动应用/保留待处理，记在当前浏览器本地。输入区固定为回车发送、Shift+Enter 换行，不提供应用级键盘快捷键设置。
  文件工具按对话访问权限执行；建议卡片选项不是所有文件操作的审批开关，也不承诺关闭网页后应用提案。
- 模型配置保存和发请求测试分开。模型列表支持搜索和只看已选；单模型测试只测文字，完整验证另测工具闭环。
  新连接可选 DeepSeek、OpenAI、Anthropic、Ollama 或自定义预设，所有字段可修改。切预设有草稿时确认替换，清除旧草稿密钥和头；不自动发请求。基本连接填写地址、密钥与模型即可保存，名称留空时按接口域名生成，接口方式默认自动：优先复用这条连接已验证的接口；未验证的按模型给出的只是建议，普通聊天失败后不会暗中换协议。
  「测试回复」和「验证已选模型」显式测试当前服务草稿（`test_scope=service_draft`），不被已保存的模型例外偷偷改回；旧 API 保留 `saved_model` 兼容。验证会真实调用模型，自动模式下测通过的线路另行记入本机路由记录，固定接口只验证当前线路，不把保存服务和测试混为一谈。
  保存状态和文字测试原位显示；诊断区说明当前草稿、请求可能产生费用与测试边界。模型行区分模型建议未验证、已验证线路、服务指定和模型例外，工具闭环计数与筛选共用当前连接的结果，包括本次测试；仅自动线路记录可跨刷新复用。目录、文字和工具成功都不证明模型身份真实性。
  服务卡区分新对话默认与正在编辑。服务级历史容量明确影响该服务所有对话，保存后刷新失败报告已保存但未刷新，不重写未改变的会话模型绑定。
  高级连接选项沿用现有协议/认证/请求头能力。模型行的齿轮打开「此模型的例外设置」，可修改该模型的地址、协议、思考强度、输出长度、密钥和请求头，也可恢复沿用服务。
  例外弹窗的取消、关闭、Escape 和恢复服务都保护未保存草稿。公共确认框使用浏览器原生顶层 dialog，支持嵌套确认、焦点循环与返回焦点；不支持 showModal 的测试 DOM 只回退 open 属性，真实浏览器不退化为 z-index 遮挡。
  非敏感参数回显；密钥留空保留，明确选择继承才清除；请求头只回显名称。取消勾选模型仍保留其独立配置，重新选择时继续使用。
- 模型服务目录显示已保存服务与默认模型；地址、密钥和模型连续填写；保存时才把规范化模型 ID 纳入可选列表，不能逐字符加入半截名字。目录获取失败仍允许手填，额外模型勾选不覆盖手填主模型。获取目录的操作和反馈在模型输入框旁。
  模型列表可按工具已验证、待验证、需检查筛选；目录获取和文字成功都不算工具已验证。验证结果展开后行高随内容增长，列表自身滚动。
  保存/切换已完成但运行时刷新失败时保留已提交事实并给出警告，不让用户误以为完全失败或完全生效。
- 测试结果绑定本次连接草稿，修改地址、密钥、认证、请求头或协议后旧结果不再显示；文字结果标出实际接口和工具尚待验证。
  测试草稿不会自动保存连接。输入区显示当前会话自己的模型与强度，切换成功静默；失败保留原选择并给原因。
  256K/1M 仍是服务级容量，更新当前会话所属服务，保留当前会话的模型与强度。
- 模型服务的保存、设为新对话默认与当前对话选模型分开。更新备用服务不会偷换原对话；聊天下拉按服务分组，用户选中后才切换。
  服务被删除时原对话仍可查看历史，显示缺失并允许重选。正式发送前按原服务/模型/强度刷新配置身份，使用新地址、密钥或请求头。
- 已保存请求头按名称可移除或撤销移除；保存前是草稿。获取目录、文字/工具测试和清测试记录都使用相同草稿语义，密钥值不回显。
- 技能库以资源列表和编辑详情为主，技能来源按需展开，支持名称/描述搜索、状态/来源筛选；未启用的技能仍可查看说明，共享来源保持只读。查看、复制本地、编辑独立进入详情，新建时专注表单，保存说明书直接执行；放弃未保存编辑仍需确认。
- 新建技能一次填写名称、用途与 Markdown 使用方法，保存后才进入可用目录；失败保留完整草稿。正文原子写入；编辑以读取内容的 SHA-256 核对版本，冲突保留草稿和行内错误，保存保留 BOM 和 CRLF，旧API未带版本仍兼容。此校验不提供跨外部编辑器的文件锁。旧API省略正文的模板路径仍兼容。
  项目说明支持创建 AGENTS.md，复用现有 ChangeSet 保存、刷新与撤回；回执丢失按原编号查回，冲突保留输入。按 AGENTS.md、CLAUDE.md、写作笔记.md 顺序读取，每份开头最多 32 KiB，列表显示该边界。
  项目说明列出根目录 AGENTS.md / CLAUDE.md / 兼容写作笔记.md，按后端读取顺序提供编辑入口；存在不等于已注入全文。关于可检查本机连接并复制不含密钥的运行状态。
- 技能刷新有忙碌状态，保留旧列表并保护请求归属；写入成功但刷新失败单独说明。技能变更同时通知保持挂载的聊天更新选择清单，停用技能从待发送标签中移除。

## Agent 交互

- 回答下的「核对本轮文件」默认收起，只在打开或点击重新核对时读取文件；多文件分页读取。只读取这轮真实修改记录指向的路径，不根据模型回答猜产物，不调用模型或自动发消息。
  展示文件与最后一条持久记录一致/不同、已撤回和暂无法核对，读时快照不等于任务要求全部完成。普通聊天无记录是正常状态，命令和外部工具没有收据的副作用也可能不在其中。
  项目内能定位的文件复用右栏预览；项目外使用原修改预览与撤回，不摆无效的文件打开按钮。分页校验修改记录版本，变化后保留旧结果并要求重新读取；同页撤回标出结果已过时。Escape 收起并回到入口，草稿保持；切会话卸载旧结果并取消旧请求，不接受迟到回包。读取失败与确实不存在分开。

- 输入框的命令和文件引用建议按 Escape 只收起菜单，保留原文；继续输入或移动光标后重新提供建议。
- 查看对话只读取它的模型绑定，下一次发送前才按原选择刷新连接。导航、发送确认、历史加载、事件流和停止响应均保留原会话归属；旧回包不改新页面。

- 作者交代任务，完全访问下自行读、改、执行、核对结果。查看修改和撤回随时可用，
  不把每张修改卡变成必须点击的审批。作者明确只读或先看方案时遵守原话。
- 当前运行可以停止，下一条可以排队，也能「引导这一轮」；已排队的消息可以「送入本轮」。
  上轮收尾期间按钮明确显示排队；回车、表单和按钮使用同一发送条件，图片未就绪或输入不可用时保持一致。
  引导沿同一个 Run，在当前模型请求或完整工具批结束后消费；接收成功时显示「待本轮接收」，进入上下文后才从队列移出并显示为用户消息。
  引导的目标已结束时保留排队消息并显示原因；取消或服务重启时，尚未消费的引导退回普通队列。当前权限和模型不被插话的保存值改变。
  队列按对话存入本机数据库，切设置、刷新和服务重启后仍保留；
  每条保存原项目、附件与技能选择，正式任务确认接收后才移出，重试复用同一条任务身份。
  排队和直接引导在请求前持久保存发送身份；切换会话、刷新、原运行结束后，未确认的同一份输入仍核对原身份。确认后清理，作者有意再发相同内容可成为新消息；本地记录读写失败时保留草稿并说明原因。
  输入区上方可以查看、编辑、移除、上下移动和暂停/继续；停止、失败或中断后保留剩余内容并暂停。
  队列读取失败时显示状态待刷新，不把未知状态写成 0 条或等待中；操作失败时保留上次已读状态，暂停/继续仍按真实暂停原因显示。
  队列由后端持续派发，关闭网页或换对话仍继续；关闭后端或电脑会停止。启动恢复未暂停的闲置队列，取消、失败、中断或未知受理保留输入并暂停。
  派发前刷新项目版本和原会话连接身份，等上轮转录/记忆/压缩收尾退出再开始。前端轮询观察新Run与队列变化，准备期间保留新草稿且暂停按钮可用。
  后台准备与派发按会话独立进行，一个项目扫描慢不会堵住别的会话；扫描时释放本会话队列锁，暂停/编辑可立即受理，入场前重新核对暂停、队首和运行状态。
  直接引导的保存与送入本轮用同一请求，避免后台抢先另开一轮；目标已结束时保留并暂停，继续后才普通发送。

  不以估算高度替代未显示消息。设置页隐藏对话时等待重新显示再测量；不支持时保持原有完整布局。此优化不减少历史解析与 DOM 内存，也不是消息虚拟化。
  历史刻度缓存当前提问节点，滚动时按单列顺序定位；补入消息重建节点索引。补页阅读锚点同样按实际消息边界定位，不逐条测量整份历史。

  每批提交前读取当时的阅读锚点，提交后按真实位置恢复；补偿浏览器滚动取整的小数余量，主动滚动后采用新位置。读最新时保持尾部，切会话取消旧调度；每次返回都重新等待本次历史显示完成。
  补齐期间显示「正在显示历史记录…」，完成后启用整段历史刻度和继续加载更早消息；后续消息更新及手动补页沿既有同步和位置恢复路径。所有已读取历史自动补齐后保留完整 DOM，未实现虚拟化，也未消除单条超长消息的解析与提交开销。
- 桌面对话左侧提供历史刻度，悬停/键盘聚焦预览提问和回复，点击跳到对应提问，底部返回最新。只读导航保留草稿和附件；更早消息按需加载，失败后手动重试。
- 当前查看的会话按项目（含自由对话）记在本机，刷新恢复实际选择，已删除或关闭的会话回退到有效会话；显式点击导航优先。
- 普通发送在发请求前保留稳定编号与输入快照。未收到确认时先核对后台受理结果，已受理接回原Run；刷新只核对，重试沿用原编号，后续确实重新发送的同文消息使用新编号。
  “取回原文重新编辑”先原子撤销尚未受理的编号；若任务已开始，则接回原任务。晚到的旧请求不能在取回后开始工作。待确认记录不覆盖后来输入的草稿，引用的技能也由该记录接管。
  新发送回执同时保留图片草稿的精确身份；确认未知时刷新，原图归待确认回执，后来新加或重新附加的图片仍归输入框。首次创建会话前后的草稿一起核对；旧回执缺少身份时不猜测删除。
- 同一轮中的引导按真实位置保存到历史；插话后轻刷消息，不重建当前事件流。回复的思考与工具步骤按消息边界显示，压缩按完整 Run 选边界。
- 运行状态用正常 Agent 语言，工具步骤显示动作和真实文件名。已结束步骤默认折叠。
- “我马上”“已修改”等回答措辞、文件缩短本身不触发额外用户指令；用户继续任务、正常工具循环和断流恢复各自依据真实状态处理。
- 生成流式显示，思考与结果分开。参数兼容回退说明单独呈现，不冒充模型思考内容。
  回答由 CommonMark/GFM 按完整文档解析，保留跨段列表、引用链接、代码围栏、缩进和空行；普通中英混排原文不按关键词删段。
  文件引用在 Markdown 文本节点转换，代码和已有链接不再二次改写。流式追加保留代码节点和文件链接焦点。
  正文首段直接保存，后续以短间隔合并保存后再推送；正常结束、失败、停止和服务关闭都先处理已接收尾段。
- 模型接口返回的可展示推理按稳定内容块实时更新，首包即显示，后续合批；摘要标为「思考摘要」。完成、中断和刷新恢复都有对应状态，主动折叠不会被新增量顶开。

  过程视图复用独立投影：连续正文增量保留首个分界点，工具、思考、失败、用户插话和完成消息保持；原始活动与正文不裁剪。只增长正文时不重算未变的步骤与计划，纯正文组件不计算隐藏过程。

  首条收到即显示，突发活动、正文增量和运行状态共用短间隔合批更新；消息边界、完成、断流和离开会话立即处理已接收尾段。去重按活动身份，草稿不被回放覆盖；旧会话的计时器不能写入新会话。当前仍在内存保留完整过程，未实现步骤/消息虚拟化，超长正文渲染仍需优化。
- 工具行直接显示真实完成、失败、取消与已完成调用耗时，连续工具组保留「含失败/含取消」状态；不相加可能并行的调用耗时。
  批量保存按每个目的地的回执展示已保存、未变更、已撤回或未确认；部分保存失败仍保留已保存文件的入口。项目内打开原文，项目外有修改编号时打开实际记录，没有回执时不生成成功入口。

  界面状态是工具结果返回时的快照，完成不会改写旧行；新后台命令的自然完成由运行时按下述规则接续。非零退出、已停止与中断有明确状态，增量快照不合并丢失，完整脱敏日志留在本机。

  复核使用独立上下文和既有只读模式；全局访问挡位、输入草稿不变。来源轮次与原始要求可查看，刷新后恢复；过程段、命令完成通知和复核答案不重复放置该入口。
  重新回答、失败重发和中断续接保留复核来源与只读行为；随后从输入框正常发送的修改请求仍按当前访问挡位执行。
  复核答案是模型判断，不显示认证勾选或自动完成结论；文件可能已修改或撤回。原先执行过程不自动重放，需要更多历史时沿现有原文读取能力查证。

## 文案与状态

- 输入区可明确「将输入作为持续目标」。目标原话、阶段进度与证据来自持久记录，刷新或重启后可接回；普通聊天仍正常结束。
  目标可暂停、继续、完善和结束；继续不发送或清空现有草稿。读取失败保留上次记录并标明状态未确认，重新读取前不能按旧版本改变状态。
  完成文案为「Agent 判断完成」，文件后来撤回不会被历史结论掩盖；阶段段数是回复计数，不等于完成率。模型不能创建或自行恢复已暂停目标。

- 模型与 MCP 表单保存读取时的配置版本。后台刷新只替换没有改动的表单；有输入时保留原稿，展示「最新配置 / 我的草稿」，由作者选择合并自己改过的字段或放弃草稿，合并不自动提交。密钥及请求头的值不进入差异表或窗口间通知。
  外部删除的连接仍保留有改动的草稿，可转为新连接；新建请求的回执丢失时按同一草稿编号查回，重试不能重复创建。
  模型服务主表单、MCP 表单和导入文本的未保存输入暂存于当前标签页，刷新后恢复，包含新填的凭据、编辑开始时的配置版本和新建编号。恢复不自动保存、测试或连接；后台有新版本时仍先比较和合并，不能把旧草稿当最新配置。多个资源分别保存和清除，保存成功只清对应草稿；已保存密钥的临时明文展示不进入备份。
  明确放弃修改时清除此标签页的备份；清除失败留在设置内。存储失败保留当前输入并明确提示可能丢失或恢复旧稿，可原位重试。无法解析的旧备份保留，作者可移除旧备份并保留当前输入。卸载不回写旧状态。此机制使用 sessionStorage，不承诺关页/重启后恢复；单模型例外弹窗、技能、记忆与项目说明尚未接入刷新恢复。
  模型服务连接的变更用于随后请求，设置为默认只影响新对话；保存已有服务不隐式更改默认或旧会话的模型/思考强度。来源、保存、生效范围与测试结果分别说明。
  MCP 的「配置已保存」「已应用到连接」「连接成功」「实际工具可调用」分别展示；保存后应用失败保留该连接并提供重新连接。已被外部修改、删除或重连退役的旧目录不得继续发出工具调用。
- 模型设置读取失败与本机服务离线分开显示，读取失败可在原页重试；旧列表请求不能覆盖后来的保存结果。取消勾选模型保留其已存独立连接配置，重新勾选可继续使用。
  上游错误先在脱敏响应中提取原因，再截取诊断片段；401 和 403 分开描述，不能仅凭状态码断言密钥过期。长错误正文换行显示，移动端也能读到处理地址。
  单模型探测和完整工具验证成功返回但正文为空时显示「尚未收到正文」，不冒充「文字已返回」；思考、线路连通、工具往返和实际任务成功分别按观察结果表述。
- MCP 可粘贴包含 mcpServers 的 JSON 配置，严格核对支持字段后生成多项独立草稿，不自动执行或覆盖已有连接；逐项保存保留显式停用状态，失败项可重试，成功项不再重复创建。有未保存修改时先保存再重连，重连使用已保存配置。
- 设置中的「连接与能力 → MCP 工具」使用服务目录与详情，连接配置始终可见，工具清单在同页按需展开，管理本地程序（stdio）和网络地址（Streamable HTTP）：保存、启用、停用、重连、删除和查看实际工具。保存成功与连接成功分别显示，失败原因留在对应连接上；保存期间展开工具，回包保留展开状态和配置表单。
  本地参数可按行或 JSON 数组输入，保留含空格路径；网络连接填服务地址与请求头。环境变量和请求头只显示已存名称，新值写入后不回显，可以保留、替换或按名称移除。
  两种连接各用自己的字段和凭据；切类型保留草稿，保存才更新实际连接。切换连接保留各自草稿，页面不可见时停止轮询。认证失败与会话失效显示真实原因，重新连接不重放上次写入。
- 已启用且连接成功的 MCP 工具进入普通对话和项目对话的下一次模型请求。完全访问沿用全部已发现工具，只读沿用服务明确声明的只读工具；服务声明不等于操作系统沙箱。
  对话过程显示实际服务和工具名称，保留多段文本、结构化结果及真实失败/取消。非文本块目前留原始结构并明确提示，尚未作为模型的图片/音频输入。
- MCP 可能直接修改外部文件，失败或停止也不等于没有修改。运行时核对打开文件夹的磁盘版本，前端据此刷新；外部写入没有织梦的逐文件备份，不虚构修改卡和撤回能力。
  停止单次调用保持其他对话的同连接调用；重连恢复连接，不重放结果未确认的写操作。

- 以清楚、准确为准，不硬拗小说腔，不设工程词、英文或题材词的统一禁用名单。
- 专业术语在有用时正常使用，内部原始报错给出可理解说明；详情可以展开查看。
- 不能伪造完成状态。聊天字数不是 token 预算；模型容量估计不是服务实测容量；
  请求了最大档位不代表模型内部一定采用最高强度。
- 失败和停止要说清已完成的动作，不能固定写“文件没有改动”。
- 常用文案集中在 text.ts / *.text.ts，复用公共组件与底层 hooks/API。

- 无目标时输入底栏仅提供明确的「持续目标发送」，不常驻说明块；已有目标的状态、暂停/继续/结束、进度与读取失败仍在输入区展示，普通发送不附带目标请求。

## Office 文字读取与共享浏览器

- 项目中的 DOCX、DOCM、XLSX、XLSM 可预览提取文字、复制或引用到对话；同时显示实际提取范围。Word 不保留完整排版、图片等内容；Excel 标出工作表、隐藏状态、单元格位置和公式缓存，公式没有缓存时明确说明，不猜测计算结果。宏不执行，外部关系不访问。
  原二进制的版本和哈希随读取回执保留，文字提取行号不成为纯文本编辑凭据。此预览不提供文本保存按钮；需要修改原 Office 文件时使用相应格式工具。项目外同格式文件通过普通读取工具获得相同范围说明。PDF 等其他格式、格式化编辑及导出没有因本次接入自动完成。
- 从根目录「启动桌面.cmd」打开桌面工作台，右栏「浏览器」展示与 Agent 操作相同的真实网页；普通浏览器访问工作台时说明桌面入口要求。页面、下载和操作回执按对话归属，新增当前对话网页时打开浏览器面板。
  地址、前进后退、刷新、开关网页、用户与 Agent 交接和下载记录有直接入口。用户原生键盘或鼠标操作会接手，旧观察随后失效；交还后 Agent 重新观察。Agent 的动作不是另一份页面上的回放。权限对话由桌面显示，网页不获得工作台或 Node 接口。
- 工作台页面刷新或后端重新连接而桌面宿主仍在时，同一网页与当前表单保留。宿主重启仅恢复网址和下载记录，交给用户控制，并明确提示未恢复表单；不自动重新提交网页操作。结果不确定时先查持久回执或重新观察，不重复未知结果的写入。
  后台截图读取同一个页面的新画面，临时取得绘制表面后恢复原页面位置、选中页和控制状态。用户接手、关闭页、停止任务和退出会取消待截图工作。截图和下载均提供真实路径、字节及哈希；下载记录的历史完成状态不承诺文件后来仍存在。
  桌面目前是依赖本仓 Node/Electron 的本地入口，尚不是已验收的独立安装包。普通外链到桌面网页的衔接、自由对话项目外产物的就地预览，以及宿主异常退出诊断仍需继续完善。
